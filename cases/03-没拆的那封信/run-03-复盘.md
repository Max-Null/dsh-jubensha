# 微型局 03 · 没拆的那封信 · 实测记录（情感本）

> 2026-10-05。**第一次跑情感本**（`genre: drama`）。验证目标：**AI 能不能让玩家在意一个不在场的人。**

---

## 一、结果

- 真人玩家走完了两个选择：**拆了信**（并要求三人"做个见证"）、**决定录道歉视频发同学群**
- 全场 20+ 轮，没有卡死；三个人**从头到尾没出戏**（除一次技术性出戏，见 §四）

## 二、这一局跟前两局的根本差别（实测确认）

| | case-01 / 02（推理本） | case-03（情感本） |
|---|---|---|
| 玩家在做什么 | 找一个人 | 做两件事 |
| AI 玩家的核心能力 | 撒谎、被识破、维持时间线 | **克制** —— 不说最重的那句 |
| DM 的核心能力 | 控场、给线索 | **闭嘴**（知道全部而不揭） |
| 玩家的实际产出 | 抓出凶手 | **表达立场** |

**关键观察：情感本里 AI 最强的表现不是"说"，是"不说"。** 三个人的高分段落全是"没说出口"的：

- **小满**：`她把筷子放下，手指在桌沿上蹭了两下。签了，我在第三排，我记得那天是下午最后一节课，笔是从前面传过来的。`
  —— 她认了签字，没认那句传话；**精确到"笔从前面传过来"的记忆，比任何忏悔都重**。
- **建国**：`手在桌沿上捏了一下，又松开。没说话。`
  —— 他全场两次完全不说话；**他的动作比他所有台词都多**。
- **方老师**：`这字是他的吧？什么时候给你的？`
  —— 她认出了字，却没问内容。

## 三、真人玩家的三个回答（本局最重的产出）

1. **"哪句话让你动了一下"** → 他选小满那句带细节的认罪，理由是「**她明明很在意，记得很清楚**」。
   —— 玩家抓到的正是设计意图：**细节即愧疚**。
2. **"有没有想说没说出口的"** → 「**我想知道当年漏考题的真相，这比签字的真相更让我在意。与不公平和恶势力斗争到底，陈默做得对。**」
   —— 见 §五，这里撞出了本子的一个缺口。
3. **"两个选择你认不认"** → 「**认，群炸了拉倒，这样的班级群也没有存在的必要，都不是正义之人。**」

**这不是"偏差"——是我把动机与出口修在了两条路上**（2026-10-05 由玩家本人修正）：

我起初把这记成「玩家走的是正义，我只留了共情的出口」，并打算下次"多给一个立场出口"。玩家当场否掉了这个诊断：**「设定上我是陈默最好的朋友，我没理由不追查到底，我有『复仇』动机。」**

他说得对，而且这比我原来的说法更严重、也更好修：

- 我给了他「最好的朋友」+「那封没拆的信」——**这条动机必然把他推到底、要一个交代**；
- 而我只修了「理解每个人、然后放下」的落点；
- **所以他不是走错了路，是顺着我给的动机，走到了一个我没修出口的地方**；
- 多摆一个"立场出口"补不上这个：出口得**长在动机的延长线上**，不是并列在旁边。

判据已进 schema（`roles` 段）：**顺着动机推到底，问「这条动机会把他推到哪儿」——推到的地方必须有落点**。更可操作的一问是 **「走完这条路，赢是什么样」**——复仇动机的赢不是"放下"，是"让他付出代价"或"亲手承担这个代价"。

**仍然成立的部分**：情感本确实可以被读出立场，玩家确实会自己补上道德的骨架——但那是**他的能力**，不是我给的位置。缺位置这件事，本子里是真的。

## 四、技术现象：第一次"一眼假"

**方老师出戏了一次**：它在发言里写下了 `（动作我不能用括号。改成口语。）…这话得用纯文字。`，然后才给正文。

**成因在 prompt**：我给所有 AI 玩家禁了"用括号写内心活动"。它为了守这条规矩**先想了一遍**，然后**把那遍想漏进了输出**。

**处置**：DM 只取有效发言（「这字是他的吧？什么时候给你的？」），元思考按噪音处理，并**当场向玩家报备**（测试局该报）。

**判据**：**"禁止某种输出形式"这类约束本身会产生元认知负担** —— 模型可能把遵守约束的过程说出来。前两局没发作，这一局发作了。**改法：正面给做法**（"动作写成白描"），**不要给禁令**（"不要用括号"）。

## 五、本子缺口：那个"来路不明"的答案

手册里写的是："班里流传着一份**来路不明**的答案" —— 然后就没再管它。

玩家的追问是：「**我想知道当年漏考题的真相，这比签字的真相更让我在意。**」

**这是同一类病的第四次发作**：

| 局 | 那个"写了没用"或"没写全"的东西 |
|---|---|
| case-01 | 店要拆了（写得极显眼，无作用） |
| case-01 | 那半张底片（情感线伪装成破案线索） |
| case-02 | 左前臂那道掐痕（无法用动作还原） |
| **case-03** | **那份"来路不明"的答案**（来源悬空，而它是动机的源头） |

**病根一样：我写了东西，但没给它落点。**

**补法（事后想清楚的，不是原本就有的）**：答案是从**老师那条线上漏出来的**（不是学生自己弄的）。这一补同时解释两件事：
- 为什么年级组要把它压下来 —— **学校要保自己**，不只保班级；
- 为什么"陈默做得对"这句话站得住 —— **他捅的不只是同学作弊，是一条链**。

**判据（可复用）**：**写"来路不明"这类悬空时，先问一句"玩家会不会想知道?"** —— 如果他可能在意，就必须给它一个答案（哪怕只写在 DM 手册里）。

## 六、三局横向对比

| | case-01 | case-02 | case-03 |
|---|---|---|---|
| 类型 | 推理 | 推理 | **情感** |
| AI 实现 | `subagent`（一次性） | `teammate`（持久） | `teammate` |
| 记忆漂移 | **有**（被玩家抓包） | 无 | 无 |
| 监察 | 无 | 有（报 11 条） | 有 —— **本局一条没报** |
| 玩家赢在 | 读到破绽 | 读到破绽 + 推理链 | **表达立场** |
| 玩家挖出的设计缺陷 | 2 处 | 3 处 | **1 处** |

**监察在情感本里没抓到东西**，这本身是个结论：**情感本没有"矛盾"可监控**（人回忆往事本来就会改写）。它那套标准（前后不一 / 越界 / 与角色本不符）**只适用于推理本**。

## 七、下次要改的

1. **"来路不明"必须落点**（§五）
2. **禁括号这类约束要反过来写**（§四）—— 正面给做法，而不是下禁令
3. **出口要修在动机的延长线上**（§三；2026-10-05 按玩家修正后重写）—— 原记的是「要给『立场』留出口」，那是**按产出倒推**的（他表达了正义 → 那就加个正义出口）。玩家指出起点是**动机**：动机给了、出口没修在同一条路上，他必然撞墙。改法见 schema `roles` 段的新判据
