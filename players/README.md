# players — 常驻牌友池

这个目录存的是**玩家**，不是角色。

- **玩家**（本目录）：这个人**怎么玩游戏**。跨局稳定，是「树干」。
- **角色**：本局剧本里他演谁。每局不同——那是「分叉」的临时附着物，放在各局自己的目录下。

一个玩家在不同本子里演不同角色，但**玩法风格不变**：老陈演凶手还是演无辜，他都是那个不说话的。

## 设计要点

1. **三种盲区必须不同**（见上表右列）——这是「读人」信息的来源。如果三个人盲区一样，玩家就没有可学习的空间；也正是这一列让「针对不同人用不同骗法」成为可能。
2. **每张卡都写「他做不到什么」**——人设的戏剧性来自**欲望与能力的缺口**，不是形容词堆叠。判据见 `docs/设计/2026-10-04-单机剧本杀-设计方案.md` §2.3–2.4。
3. **跨局生长**：第一局这三个人没有历史。从第二局起，「对这个人的印象」（谁骗过我、我冤枉过谁）通过记忆层累积——**本目录只存稳定的风格，具体经历留给记忆**。
